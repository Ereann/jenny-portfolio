HOW TO UPLOAD TO GITHUB PAGES:
1. Unzip this folder.
2. Upload/replace BOTH:
   - index.html
   - assets/ folder
3. Make sure index.html is in the root of the GitHub repo.
4. Commit changes.
5. GitHub Pages will update automatically.

IMPORTANT:
Do not delete assets/images. The website uses those image paths.
